- Eleven initial regression cases reproduced linked/outside skill reads, unreadable/invalid UTF-8 crashes, FIFO blocking attempts, recursion exhaustion in a valid 2,000-node dependency chain, unbounded cycle handling and corrupt-packet crashes. Four additional guarded-reader regressions reproduced unsafe state/packet file opens without actually opening a FIFO or private data.
- Skill discovery now rejects linked roots, directories, document links and non-regular files before reading; encoding/permission failures become invalid-skill findings. Failed discovery no longer implies a new skill should be created. Removed duplicate discovery passes in doctor/validation/cache generation. Legacy helpers reuse the existing tree guards and canonical mandatory-rule list; synthetic canary tests cover both helper entrypoints and linked registry content.
- State/packet readers reject links, Windows reparse attributes and special files; corrupt UTF-8 packets produce a controlled repair diagnostic. Packet repair preserves canonical bytes. These local checks do not sandbox another process with the same OS account changing trusted parent directories during a read.
