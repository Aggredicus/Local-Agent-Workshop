# Autonomous Agent Policy

Autonomous agents may run for extended durations and may work on complex or sensitive areas inside isolated branches, mocks, simulations, and test environments.

Agents may:

- analyze,
- plan,
- code,
- test,
- document,
- refactor,
- build repo graphs,
- generate review cards,
- and prepare safe patches.

Agents must:

- respect branch policy,
- checkpoint long work,
- write Chronicle events,
- produce verification evidence,
- preserve resumability,
- and pause at human approval boundaries.

Agents may prepare sensitive work, but may not activate sensitive consequences without explicit human approval.
