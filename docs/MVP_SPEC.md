# MVP Spec

## v0.1 must do

- Normalize the repository structure.
- Initialize repo governance files.
- Read `.branch-policy.yaml`.
- Create or classify an `agent/*` branch.
- Create Chronicle events.
- Generate a review card.
- Generate a morning report.
- Run placeholder verification scripts.
- Support approve/reject/modify/resume concepts at the file level.

## v0.1 does not need to do

- Full dashboard.
- Real Telegram/Signal integration.
- Full repo graph analysis.
- Real multi-agent orchestration.
- Production deployment.
